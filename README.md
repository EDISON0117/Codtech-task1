Description:
A console-based Banking System built in Java that simulates real-world banking operations. 
Users can create accounts of three types — Savings, Checking, and Fixed Deposit — secured with a PIN.
The system supports core banking features like deposit, withdrawal, fund transfer between accounts, and full transaction history.
An admin view allows listing all registered accounts. Minimum balance of 500 is enforced on withdrawals to simulate real banking rules.

Conclusion:
This project demonstrates the use of Java OOP concepts like classes, objects, and encapsulation.
It covers HashMap for data storage, Scanner for user input, and menu-driven console interaction.
It is a strong beginner-to-intermediate level project that reflects real-world banking logic and is ideal for understanding how data flows between classes in a Java application.
